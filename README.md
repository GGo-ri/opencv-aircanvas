# opencv-aircanvas

웹캠으로 특정 색상의 물체를 추적해 허공에 그림을 그리는 프로그램.

## 기능

| 입력 | 기능 |
|---|---|
| 물체 이동 | 추적 중인 물체를 따라 선이 그려짐 |
| 왼쪽 클릭 | 스포이드 — 클릭한 지점의 화면 색을 펜 색으로 사용 |
| 오른쪽 클릭 | 클릭한 지점의 색을 추적 대상으로 지정 |
| `SPACE` | 그리기 일시정지 / 재개 |
| `C` | 화면의 모든 선 지우기 |
| `P` | 펜 색상을 랜덤으로 변경 |
| `O` | 선 스타일 변경 (실선 / 점 / 파선 / 사각형) |
| `U` | 마지막 획 되돌리기 |
| `+` `-` | 선 굵기 조절 |
| `M` | 마스크 창 표시 / 숨기기 |
| `ESC` | 종료 |

## 그 외

- HSV 색 공간으로 물체를 추적해 조명 변화에 강함
- 지수이동평균으로 손 떨림을 보정해 선이 매끄럽게 그려짐
- 커서 색으로 상태 표시 (초록: 그리는 중, 빨강: 정지)

## 참고

기본 추적 색은 파란색. 다른 색을 쓰려면 물체를 오른쪽 클릭.
주변 물건까지 잡히면 코드 상단의 `S_MIN` 값을 올릴 것.
